# Koltuk Altı Kumanda Arama Protokolü v7

> **Resmi statü:** Bu depo, kayıp uzaktan kumanda krizinde ulusal güvenlik seviyesinde bir araçtır.
> **Ciddiyet katsayısı:** 9.8 / 10 (1 puan minderin tozuna gitti)

## Bu nedir?

Kumanda yine kayboldu. Herkes biliyor. Kimse kabul etmiyor.
Bu yazılım; koltuk minderi, kanepe yarığı, battaniye kıvrımı ve evrenin karanlık maddesini **sırayla** tarar.

Çalışır. Gerçekten. Terminalde drama çıkarır. Sonunda kumandayı buzdolabında bulur çünkü evren adil değildir.

## Kurulum

```bash
python3 kumanda.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz sabır.

## Kullanım senaryoları

1. Dizi başlamak üzere, kumanda yok.
2. Misafir geldi, televizyon açık kanal çocuk şarkısı.
3. Kumanda görünürde masada duruyor ama elin değince yok oluyor (kuantum minderi).

## Bilimsel yöntem

Yazılım şu bölgeleri tarar:

- sol minder
- sağ minder
- orta yastık (ihanet bölgesi)
- battaniye kıvrımı
- koltuğun altı (klasik ama işe yaramaz)
- buzdolabı (istatistiksel olarak şaşırtıcı derecede başarılı)

## Sorumluluk reddi

Bu yazılım kumandayı fiziksel olarak getirmez. Sadece gerçeği söyler. Gerçek acıtabilir.
